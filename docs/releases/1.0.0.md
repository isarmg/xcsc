# XCSC 1.0.0

当前唯一 Rust crate 的软件版本统一为 `1.0.0`。客户端能力清单、配置清单、进程通信、移动 FFI、数据库结构指纹算法及密文封装的自有版本均为 `1`；第三方依赖和外部标准的版本保留实际要求。当前接口不承担旧版本兼容或数据迁移。

客户端通过 `xcsc::<module>` 直接使用公共机制。桌面运行接口、日志、本机状态、私有文件检查和业务适配器保持明确边界；移动平台使用受功能开关约束的 FFI 和 JNI。Linux 的离线维护接口由独立安装、升级工具显式启用，运行中的服务端不执行这些操作。

产品固定精确 `=1.0.0` 和当前完整 Git revision，并更新锁文件后重建。基础库不独立安装或运行服务；安装、配对和业务数据的校验由对应产品完成。

构建、原生平台验证和产品接入见[开发指南](../development.md)及[发布来源](../split-origin.md)。
