# XCSC 1.0.5

当前秘密封装增加 `open_with_domain` 和 `seal_with_domain`，由调用方明确传入可信定义材料中的 domain、revision 和 binding。泛型入口调用同一当前格式实现；真实固定向量验证 KDF、AAD、解密、域隔离和篡改拒绝，不尝试历史格式。

公共 CLI 只接受当前 `--config` 和 `--format`，移除 `--state`、`--output`、`--json` 旧别名。未知旧选项明确拒绝，不能触发默认配置或安装副作用。服务身份核验同样只接受注册的 `--config` 入口。

删除已无消费者的维护 pending 标记和共享启动门禁。实例锁只管理自己的运行互斥；工具的独立排他管理锁、受控文件描述符以及真实私有权限和文件身份检查继续保留。Server 不参与工具间交接。

消费者来源门禁检查真实官方 Git 来源、包身份与完整 revision，允许无关 registry 包采用相似名称前缀。公共库 CI 独立验证自身与合成消费者夹具，不扫描下游项目。
